# Cocovalt landing page → WordPress — build brief for Claude Code

## Goal
Turn the approved static design in this folder (`index.html` + `assets/`) into a working **WordPress** page that looks and behaves exactly the same. The design is final, so match it rather than reinterpreting it.

Open `index.html` in a browser first. It is the visual and behavioural reference.

## Recommended WordPress approach
Pick whichever fits the existing site. If unsure, use **Option A**.

**Option A: custom page template in a child theme (most faithful)**
1. Create (or use) a child theme. Add `page-cocovalt.php` with a `Template Name: Cocovalt Landing` header.
2. Move the CSS into `assets/css/cocovalt.css` and the JS into `assets/js/cocovalt.js`. Enqueue them **only on this template** (`wp_enqueue_scripts` + `is_page_template()`). Enqueue the Google Fonts URL the same way.
3. Copy the `<main>…</main>` markup into the template. Replace every `assets/...` image path with `get_stylesheet_directory_uri() . '/assets/img/...'`, or upload the images to the Media Library and use those URLs.
4. The template should call `get_header()` / `get_footer()` only if the site keeps a header and footer. The design is a full-bleed page with no header/footer, so a blank template (`wp_head()` / `wp_footer()` only) is preferred.
5. Create a page, assign the template, and set it as the static front page (Settings → Reading).

**Option B: block theme / Gutenberg.** Use a "Custom HTML" block for the markup, plus a small plugin that enqueues the CSS and JS on that page. Less editable, but quick.

**Option C: Elementor or another builder.** Only if the site already uses one. Put the sections in HTML widgets and the CSS/JS in the page's custom code. Check that the builder doesn't add padding or containers that break the full-bleed hero.

Make the editable text (the Cocovalt description, the three Pandughar paragraphs, the button label and URL) **editable in wp-admin**. Use ACF fields or the page content where practical, rather than hard-coding them.

## Page structure and behaviour (must match)
### 1 · Hero (dark chocolate)
- Full-width section with a minimum height of 900px. The background photo **always shows edge to edge** (`width: min(104cqw, 178.7cqh)`, using container query units), feathered with a CSS mask. The photo slowly zooms between 1.00 and 1.04 over 28 seconds.
- Effects layered on top:
  - 28 tiny rising "cocoa dust" particles, generated by JS
  - a slight tint and a vignette
  - a soft dark "breathing" glow behind the logo
  - an eased 300px fade at the bottom into the gold section
- **Logo** (cream, 280px wide), centred, inside a `<button>`:
  - It stays still until hovered. On hover it floats slightly and tilts toward the cursor (no more than 8°).
  - A thin ring pulses around it until it is clicked.
  - The hint under it reads "Click to explore", then "Click to close".
- **On click**, it toggles `.is-open` on `.stage`:
  - The left glass panel (Cocovalt description) slides in.
  - The right glass panel ("A Concern of Pandughar Group" white lockup) slides in, vertically centred to the left panel.
  - Two thin curved SVG arrows draw from the logo to each panel.
- A "Scroll" cue with a bobbing chevron sits under the logo and smooth-scrolls to `#group`.
- The background photo has a small parallax (up to ±10px) that follows the mouse.

### 2 · Pandughar Group (pale gold `#F5E5BB`)
- The colour "A Concern of Pandughar Group" lockup (720px max) is centred, with a maroon divider underneath.
- Two columns: three paragraphs plus a maroon "Learn more" pill button on the left, and a white card with the concerns logo grid on the right.
- **Action needed:** the "Learn more" button is `href="#"`. Ask the owner for the Pandughar Group URL.

### 3 · Under-construction tape
- A full-width dark-chocolate tape (`#3B2116`) with faint cream diagonal stripes on its top and bottom edges.
- White "WEBSITE UNDER CONSTRUCTION" text in Barlow Condensed 600 with wide tracking, scrolling slowly (56 seconds per loop).

## Responsive (already in the CSS — keep it)
- **1100px and below:** the hero stacks vertically, in this order:
  1. the logo
  2. the Pandughar panel
  3. the description panel
  4. the "Scroll" cue

  The arrows are hidden. The panels take **no space** until the logo is clicked, then expand. The Pandughar section's two columns wrap into one.
- **600px and below:**
  - smaller logo (about 240px)
  - tighter padding
  - smaller body text (16–17px)
  - slimmer tape (42px)
- `prefers-reduced-motion`: all animations are turned off.

## WordPress-specific checks
- Scope all CSS under a wrapper class (for example `.cocovalt-landing`), or load it only on this template, so it doesn't clash with theme styles. Watch for theme rules on `button`, `img`, `a`, `p` and `h2`.
- Make sure the theme or builder doesn't add max-width containers or padding around the hero. It must be full-bleed.
- Keep `<button>` for the logo, which matters for keyboard and accessibility. Keep `aria-expanded` updating.
- Convert the images to WebP in the Media Library (or with a plugin) and keep `loading="lazy"` on below-the-fold images. **Don't** lazy-load the hero photo or the logo.
- Add meta title and description (Yoast/RankMath or `wp_head`), a favicon made from `cocovalt-logo-original.png`, and an Open Graph image.
- Test on Chrome, Safari (including iOS) and Firefox, at 1440, 1280, 1024, 768 and 390px widths, with the logo panels both opened and closed.
